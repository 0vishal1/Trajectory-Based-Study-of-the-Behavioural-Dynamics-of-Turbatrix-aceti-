# Trajectory-Based Study of the Behavioural Dynamics of Turbatrix aceti

## Project Overview

An ongoing BTP project investigating the locomotory behaviour of *Turbatrix aceti* (vinegar eel) under three experimental conditions: normal/control, morphine exposure, and post-removal.

## Objective

To study how the locomotory dynamics of *Turbatrix aceti* change under different chemical conditions using experimental imaging and trajectory-based analysis.

## Methodology

- Prepared and observed *Turbatrix aceti* suspension in a bottom-glass Petri dish.
- Acquired image sequences using an AX200 camera at 125 fps.
- Processed image sequences using Fiji/ImageJ.
- Tracked multiple organisms using the TrackMate workflow.
- Extracted two-dimensional position trajectories from successive frames.
- Prepared the trajectory data for quantitative analysis.

## Experimental Conditions

1. Normal / Control
2. Morphine Exposure
3. Post-Removal

## Current Status

The experimental imaging and trajectory-tracking workflow has been established. Multiple organisms can be tracked simultaneously to obtain individual 2D trajectories.

The next stage involves quantitative analysis of:

- Position
- Velocity
- Position correlation
- Velocity correlation
- Mean Square Displacement (MSD)
